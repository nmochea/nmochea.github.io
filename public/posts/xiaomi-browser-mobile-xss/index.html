DOM-Based JavaScript Execution in Xiaomi Browser Reader Mode via <title> HTML Injection (Android)

November 16, 2025 · 7 min · 1394 words · Neil Mark Ochea

Summary#

A DOM-based Cross-Site Scripting (XSS) vulnerability was discovered in Xiaomi Browser’s Read Mode due to insufficient sanitization of the HTML tag, allowing arbitrary HTML or JavaScript to be executed via innerHTML.</p> <p>Although the article body is processed and sanitized before rendering, the <strong>document title is passed through <code>processTitle()</code></strong> and then <strong>injected directly</strong> into the Read Mode page via JavaScript using <code>setTitle(titleHTML)</code> <strong>without any escaping or HTML sanitization</strong>.</p> <p>This allows an attacker to embed <strong>malicious <code><iframe></code></strong>, <code><script></code>, or any executable HTML directly in the <code><title></code> tag, which executes <strong>invisibly</strong> when Read Mode is activated, even if the body appears clean and safe.</p> <h3 id="root-cause-analysis"><strong>Root Cause Analysis</strong><a hidden class="anchor" aria-hidden="true" href="#root-cause-analysis">#</a></h3> <p>The vulnerability exists in the <strong>ReadModeController</strong> class, which builds JavaScript commands to render content and title in the WebView:</p>
